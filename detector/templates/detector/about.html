About the Project

Project Objective

The main objective of this project is to classify online transactions as either legitimate or potentially fraudulent. By using machine learning, the system supports early detection of suspicious activity and reduces the risk of financial loss.

Problem Being Solved

Fraudulent digital transactions are often subtle, high-speed, and difficult to detect using fixed rules alone. This project demonstrates a data-driven fraud detection approach that learns patterns from transaction behaviour and risk indicators.

Random Forest Approach

A Random Forest model is used because it handles noisy data well, captures nonlinear relationships, and provides stronger predictive robustness than a single decision tree. It is an appropriate ensemble method for transaction-risk classification in an academic ML project.

Dataset

The application is prepared for a real financial transaction dataset that can later be integrated for training and evaluation. The current transaction form represents the feature structure used in a realistic online-fraud detection pipeline.

Evaluation Metrics Accuracy, Precision, Recall, F1-score
Primary Goal Reduce missed fraud cases
Output Fraudulent / Legitimate
Known Limitation Performance depends on data quality

This application is structured as a realistic academic prototype for a future final model pipeline. Once the final dataset is selected, the same interface can be connected to a trained Random Forest classifier and evaluated with proper validation metrics.
