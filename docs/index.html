Fake Online Transactions Using Decision Trees

This project applies machine learning to detect suspicious and fraudulent online transactions by analyzing transaction behavior, balances, and account activity. It combines a Django web interface with a decision-tree-based ensemble model to support fraud screening in a clear and practical way.

Problem Statement

Online financial systems face an ongoing challenge: fraudulent transactions can be hard to detect in real time because they often resemble normal payment activity. Without intelligent screening, suspicious transfers may be missed and lead to financial loss.

Project Objective

The objective of this project is to build a practical fraud detection system that learns patterns from transaction data, classifies payments as legitimate or suspicious, and exposes the workflow through a Django-based web application.

Why this matters

Fraud detection protects users, businesses, and digital financial ecosystems.

Financial safety

Early detection helps prevent losses from suspicious or fraudulent payment activity.

Trust and reliability

Accurate alerting supports secure digital transactions and stronger system confidence.

Machine learning in practice

Transaction data can be analyzed proactively to find patterns that manual review may miss.
